# SCP-956 audio

Four cues are supported: `Pinata_loop.ogg`, `Pinata_trigger_35.ogg`, `Pinata_trigger_200.ogg`, and `Pinata_attack.ogg`. Place mono 48 kHz OGG/Vorbis files in `EXILED/Configs/SCP956/Audio`. The loop is spatial; targeting cues are sent to the selected player. Set `audio_volume` in the plugin configuration. Missing files produce an explicit warning.

The release includes the four audio files provided by the server operator, converted from MP3 to OGG.
